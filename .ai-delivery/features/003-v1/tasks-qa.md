# V2 实时流式翻译字幕 Independent QA 计划

## 执行边界与前置

执行脚本先在五分钟内重试 DNS、TLS、`QA_HEALTH_PATH` 与 `/candidate-identity`，并逐字校验候选返回的 `deliveryId`、`candidateSha`。随后使用 QA OIDC 身份和 Azure Speech TTS 独立合成可重复的英中 WAV，通过 Playwright Chromium 的虚拟麦克风、麦克风授权与 HTTP 安全上下文参数输入真实候选页面。就绪、身份、素材生成、结果汇总及 JSON 写入均为执行步骤，不另建 IQA 任务。首次 QA 不含 Bugfix 复测，`bugfixResults` 必须为空数组。

脚本为用户流程设置语音 token、Speech WebSocket、翻译请求/响应、字幕 DOM 状态及视窗位置检查点；仅记录状态、时点、计数、HTTP 状态和脱敏错误，不记录 token。准备失败时不执行验收场景；单个产品路径失败后使用独立浏览器上下文继续其余场景。

## 验收任务

- [ ] **IQA-001 英文发言边说边出并修订草稿**
  - 追溯：`INT-001`、`INT-003`、`INT-005`、`INT-009`，`US-001`、`US-002`，`FR-001`、`FR-004`、`FR-005`，`NFR-001`，`AC-001`、`AC-002`。
  - 输入/命令：以 Azure Speech TTS 合成连续英文 WAV；Playwright 启动真实候选、允许麦克风并点击“开始字幕”，通过虚拟麦克风播放语音，连续采集 Speech/翻译网络检查点及 `draft`/`finalizing`/`fixed` DOM 变化。
  - 预期结果：片段最终确认前出现中文草稿，且持续输入期间同一当前片段至少发生一次可观察修订；不能只在停顿或结束后一次性显示。
  - 所需证据：语音开始、Speech token/连接、草稿首次出现、后续草稿变化、final 请求与固定状态的单调时钟顺序，以及失败环节的控制台、HTTP 或 WebSocket 脱敏诊断。

- [ ] **IQA-002 英文最终译文替换并固定**
  - 追溯：`INT-002`、`INT-006`，`US-002`，`FR-006`、`FR-008`，`AC-003`、`AC-004`。
  - 输入/命令：合成包含两个明确英文片段和片段间停顿的 WAV；Playwright 播放后记录首段草稿、final 翻译请求、首段固定及第二段字幕变化。
  - 预期结果：首段完整中文译文原位替换草稿并进入 `fixed`；第二段产生和固定期间首段文本、状态及片段标识均保持不变。
  - 所需证据：两个片段的翻译请求/响应状态、首段固定前后连续 DOM 时间线、最终固定列表和不可变性比较。

- [ ] **IQA-003 中文原文流式直显**
  - 追溯：`INT-003`、`INT-004`，`US-003`，`FR-002`、`FR-003`、`FR-007`，`AC-005`。
  - 输入/命令：以 Azure Speech TTS 合成内容明确的中文 WAV；Playwright 播放并记录发言期间的当前字幕、Speech 连接及所有 `/api/translations` 请求。
  - 预期结果：中文识别原文在发言期间逐步出现并更新，内容与合成中文语义一致，且整个中文流程不发出翻译请求。
  - 所需证据：合成素材标识、至少两次中文当前字幕变化、Speech 输入检查点、翻译请求计数为零及最终 DOM 状态。

- [ ] **IQA-004 固定视窗追加与自动跟随**
  - 追溯：`INT-006`、`INT-007`，`US-004`，`FR-008`、`FR-009`、`FR-010`，`AC-006`、`AC-007`。
  - 输入/命令：合成足以产生多个最终片段并超过当前视窗容量的英文 WAV；Playwright 记录初始与最终视窗尺寸、固定片段顺序、`scrollHeight`、`scrollTop` 和 `clientHeight`。
  - 预期结果：新片段使用唯一标识依次追加到既有字幕之后，早期固定字幕不变；内容溢出后视窗高度不扩展且自动停留在底部。
  - 所需证据：容量前后固定列表时间线、首段不可变比较、初始/最终尺寸、溢出判定与底部位置计算，以及相关网络检查点。

- [ ] **IQA-005 英文流式字幕实时性边界**
  - 追溯：`INT-001`、`INT-009`、`INT-010`，`US-001`，`NFR-001`、`NFR-002`，`AC-008`。
  - 输入/命令：合成持续至少 15 秒且无明显停顿的英文 WAV；Playwright 以单调时钟记录点击开始、每次可见中文草稿变化、final 翻译请求与 `fixed` 出现时点。
  - 预期结果：首条中文草稿不晚于 6 秒；final 前持续至少 15 秒且草稿早于 final，相邻可见草稿更新间隔均不超过 5 秒；final 后不晚于 3 秒固定完整译文。
  - 所需证据：包含全部时点的连续时间线、素材持续时长判定，以及首现、相邻更新和 final 到固定的逐项间隔计算。

- [ ] **IQA-006 中文原文最终固定**
  - 追溯：`INT-003`、`INT-004`、`INT-006`，`US-003`，`FR-011`，`AC-009`。
  - 输入/命令：合成包含两个中文片段和片段间停顿的 WAV；Playwright 播放至首段最终确认并继续输入第二段，记录固定列表及当前片段变化。
  - 预期结果：首段完整中文识别原文进入 `fixed`；第二段出现和固定后，首段文本、状态及片段标识不变。
  - 所需证据：首段 final 前后与第二段期间的连续 DOM 时间线、Speech 输入检查点、翻译请求计数为零和最终固定列表比较。

## 结果判定

六个场景均通过且 `defects`、`testGaps` 为空时，整体 `passed` 才为 `true`。已执行流程未满足批准行为写入 `defects`；仅 QA 脚本无法完成场景判定时写入 `testGaps`。候选网络、身份、运行配置、TTS 素材或 Runner 前置失败时，场景不执行，返回空的 `defects`、`testGaps`、`scenarios`、`bugfixResults`，并在 `evidence` 中记录具体诊断。
