# IQA-004 缺陷评估

## 缺陷信息

- **Bug ID：** IQA-004
- **QA Run ID：** 本次 Independent QA（关联 `NR-DLV-20261113-BCCA3652FB86-0039`，未提供独立 Run ID）
- **Candidate SHA：** `8f23a795b014acf174497f1c11b5641f1de2739c`
- **环境：** `http://20.7.107.68`

## 问题报告

多片段输入没有生成固定字幕，无法验证固定视窗底部追加、自动跟随及既有固定内容不变。

## 预期与实际行为

预期多个片段依序固定并从视窗底部追加，内容超出容量后视窗仍为固定高度并跟随底部。实际视窗维持 320px 且位于底部，但固定片段和唯一标识均为 0，核心追加行为未发生。

## 复现步骤与证据

在候选环境授权媒体并播放多片段合成音频。会话与 token 成功，控制台报告连接区域 Speech WSS，网络中无 Speech WebSocket/帧；因此没有可提交到视窗的字幕片段。320px 高度只证明静态样式，不能证明功能行为。

## 影响追踪

影响 `US-004`、`FR-008`—`FR-010`、`SC-004`、`AC-006`、`AC-007`、场景 `IQA-004`，以及任务 `T004`、`T011`、`T012`、`T023`—`T025`。

## 根因分析

`src/server/security.ts` 的 CSP 未允许 Speech SDK 实际采用的 `wss://eastus2.stt.speech.microsoft.com` 区域 origin，导致识别链在字幕状态产生前终止；安全测试未覆盖实际 CSP 连接目标。视窗组件没有收到任何 fixed segment，故 0 片段是上游产品缺陷的连锁症状。当前静态几何证据不足以判断追加或滚动组件是否另有缺陷。

## 限定范围的修复方案

只修正 Speech CSP 白名单及其 contract 测试。恢复识别后用既有真实多片段场景验证视窗，不为 QA 增加产品接口，也不在无证据时修改视窗实现。

## 回归风险

CSP 修改存在安全面和跨区域兼容风险。功能回归需覆盖片段数超过视窗容量、固定高度、唯一且稳定的片段 ID、append-only 顺序和每次固定后的底部滚动。

## 未解决证据

真实视窗追加与自动跟随尚未执行；修复 Speech 阻塞后必须重跑，才能确认是否存在被掩盖的 UI 产品缺陷。

## 分类与修复就绪决策

- **classification：** `product_defect`
- **ready_for_fix：** `true`
- **决策依据：** 产品安全头阻止产品自身依赖连接，直接导致无字幕可渲染；静态视窗存在不能使场景通过。
