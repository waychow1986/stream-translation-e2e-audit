# IQA-004 缺陷评估

## 缺陷信息

- **Bug ID：** IQA-004
- **QA Run ID：** 本次 Independent QA（未提供独立 Run ID）
- **Candidate SHA：** `7083a475b0626d45854acf935c12caa2f49a2421`
- **环境：** `http://20.7.107.68`

## 问题报告

多片段场景没有生成固定字幕，无法验证固定视窗底部追加、自动跟随及既有内容不变。

## 预期与实际行为

依据 `FR-008`—`FR-010`、`AC-006` 与 `AC-007`，多个片段应依序固定并从固定视窗底部追加，超出容量后仍跟随最新内容。实际视窗维持 320px 且位于底部，但 Speech WebSocket 为 1 个/0 帧，固定片段和唯一标识均为 0。

## 复现步骤与证据

QA 启动会话并尝试播放多片段合成 WAV。候选、token 与 Speech WebSocket 均就绪，无控制台错误或网络失败；WebSocket 没有音频帧，因而没有字幕片段进入视窗。320px 静态几何不能替代追加与跟随证据。

## 影响追踪

影响 `US-004`、`FR-008`—`FR-010`、`SC-004`、`AC-006`、`AC-007`、场景 `IQA-004`，以及任务 `T003`、`T011`、`T012`、`T023`—`T025`。

## 根因分析

真实 Speech 连接已建立，但 QA 合成音频没有形成任何传输帧。浏览器媒体设备、文件注入、权限和 HTTP 地址安全上下文由 QA 脚本控制；产品视窗只消费已识别并固定的字幕，0 帧时必然没有输入。当前证据未执行 `CaptionViewport` 的追加/滚动调用链，不能支持视窗产品缺陷。

## 限定范围的修复方案

仅修订 QA 脚本以可靠注入可采集的多片段音频，并在几何断言前要求 WebSocket 非零帧及至少一个真实 fixed segment；随后用足以超出容量的片段检查 ID、append-only、固定高度与底部跟随。不得修改视窗产品代码。

## 回归风险

音频未产生足够 final 会让内容仍不足以超出视窗；仅记录最终滚动位置会遗漏既有字幕被改写。QA 应保留每次固定后的片段集合和滚动位置。

## 未解决证据

尚无任何真实 fixed segment，视窗动态行为未被有效验证；修订 QA 后必须重跑。

- **决策依据：** 当前失败源于 QA 可控制的音频注入未产生帧；静态视窗证据不足以认定产品缺陷。
