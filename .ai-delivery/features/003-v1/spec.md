# V2 实时流式翻译字幕（边说边出）产品规格

## 产品目标与边界

本规格将已批准的 `INT-001`—`INT-010` 转化为可观察、可验收的产品行为。目标是在会议发言持续进行时提供对标 Teams、且不明显慢于指定参考实现的中文字幕：英文语音的稳定短语形成可修订中文草稿，片段最终确认后由完整译文替换并固定；中文语音直接显示识别原文。

范围包括浏览器采集语音、英语/中文候选语言自动检测、流式转写、英文流式翻译、中文原文直显、草稿修订、最终固定，以及固定视窗内从底部追加并自动跟随。英语和中文以外的源语言、中文翻译或改写、固定字幕的后续改写均在范围外。具体实时性比较边界由 `PQ-001` 待决，不影响其余行为的完整定义。

## 参与者与权限

- **会议发言人**：产生被采集的会议语音；须允许浏览器采集其语音后，范围内流程才可启动。
- **字幕参会者**：查看持续更新和最终固定的中文字幕，不具有改写已固定字幕的权限。
- **会议字幕体验**：在获得语音采集许可后呈现本规格定义的字幕结果；不得将草稿固定状态之外的新编辑能力授予参与者。

## 用户故事

### US-001 发言过程中查看流式中文字幕（P1）

作为依赖中文字幕理解会议内容的参会者，我希望在发言尚未结束时就看到持续出现和更新的中文字幕，以便及时理解正在进行的会议内容。（`INT-001`、`INT-003`、`INT-009`、`INT-010`）

### US-002 查看英文草稿与最终译文（P1）

作为字幕参会者，我希望稳定的英文短语尽快形成可修订的中文草稿，并在片段最终确认后看到完整译文替换草稿且固定，以便区分进行中的结果与最终内容。（`INT-002`、`INT-005`、`INT-006`）

### US-003 查看中文识别原文（P1）

作为字幕参会者，我希望中文发言直接显示识别原文而不被翻译或改写，以便按原语言阅读实时字幕。（`INT-003`、`INT-004`）

### US-004 跟随连续新增字幕（P1）

作为字幕参会者，我希望字幕在固定视窗底部持续追加并自动跟随新内容，以便连续查看最新字幕。（`INT-006`、`INT-007`）

## 功能需求

- **FR-001**：获得语音采集许可后，产品应在发言过程中持续采集发言人语音并产生流式转写结果，不得等到整句结束或停顿后才开始形成字幕。
- **FR-002**：产品应在英语和中文候选范围内自动检测当前源语言。
- **FR-003**：对于检测为中文的发言，产品应直接显示识别出的中文原文，不进行翻译或改写。
- **FR-004**：对于检测为英文的发言，产品应在当前片段最终确认前，将已经稳定的英文短语翻译为中文并显示为当前片段的草稿字幕。
- **FR-005**：当前英文片段的识别结果变化时，产品应允许相应中文草稿随之修订；修订作用于当前未固定片段。
- **FR-006**：当前英文片段最终确认后，产品应以该片段的完整中文译文替换草稿并将其固定。
- **FR-007**：对于中文发言，产品应在发言过程中显示当前识别原文并随识别结果更新。
- **FR-008**：已固定字幕不得再被后续识别结果、草稿修订或新片段改写。
- **FR-009**：新片段的字幕应在既有字幕之后从字幕区底部追加，不得覆盖已固定片段。
- **FR-010**：字幕区应保持固定视窗，并在新内容从底部追加时自动跟随最新内容。
- **FR-011**：中文片段最终确认后，产品应固定该片段的完整识别原文。

## 产品质量要求

- **NFR-001（实时流式体验）**：字幕结果必须在发言过程中逐步出现并随输入更新，不得退化为等待完整片段结束或停顿后才一次性出现；其与指定参考实现的比较边界按 `PQ-001` 决定。（`INT-001`、`INT-009`、`INT-010`）

除上述已由 Intent 明确要求的实时流式体验外，当前没有获批准的额外产品质量要求。

## 领域术语

- **发言片段**：从开始形成当前字幕到该内容被最终确认的一段连续语音内容。
- **流式转写**：发言尚在进行时，识别内容随语音输入逐步产生和更新的过程。
- **稳定英文短语**：在当前未最终确认的英文识别结果中，已经可用于提前翻译并形成草稿的短语。
- **草稿字幕**：当前片段最终确认前显示、可随识别结果修订的中文字幕。
- **完整译文**：英文片段最终确认后，用于替换该片段草稿的中文翻译结果。
- **识别原文**：中文语音经识别后直接显示、未经过翻译或改写的中文内容。
- **固定字幕**：片段最终确认后不再允许改写的字幕内容。
- **指定参考实现**：仓库 `references/realtime-captions-stt-mini/` 中已验证的同类实现，仅作为本次实时性与字幕体验的比较基准。

## 前置条件与触发条件

- 前置条件：会议发言人已允许浏览器采集语音；Azure Foundry 中支持本能力的语音转文本服务可用，英文场景还需大模型能力可用。
- 触发条件：发言人开始以英语或中文发言，产品收到持续语音输入。
- 英文路径触发：自动语言检测结果为英语。
- 中文路径触发：自动语言检测结果为中文。
- 最终固定触发：当前发言片段被最终确认。

## 行为模型

### US-001 发言过程中查看流式中文字幕

正常路径：语音采集获准后，发言开始即进入流式转写；在发言尚未结束时，字幕区逐步出现当前内容并继续更新（`FR-001`、`NFR-001`、`AC-001`）。

边界路径：若首个可显示内容直到完整片段结束或停顿后才一次性出现，则核心流式行为失败，而非可接受替代路径（`AC-001`、`AC-008`）。

### US-002 查看英文草稿与最终译文

正常路径：检测为英语后，稳定英文短语形成中文草稿；识别结果变化时草稿可被修订；片段最终确认时，完整译文替换草稿并固定（`FR-002`、`FR-004`—`FR-006`、`AC-002`、`AC-003`）。

替代路径：当前英文片段可经历零次或多次草稿修订；无论修订次数，最终确认只产生一个固定结果，后续内容不得改写该结果（`FR-005`、`FR-006`、`FR-008`、`AC-004`）。

### US-003 查看中文识别原文

正常路径：检测为中文后，发言过程中的识别原文逐步显示并可更新；片段最终确认后固定完整原文，全程不进行翻译或改写（`FR-002`、`FR-003`、`FR-007`、`FR-011`、`AC-005`、`AC-009`）。

范围边界：检测候选仅限英语与中文；其他源语言不承诺识别、显示或翻译行为。

### US-004 跟随连续新增字幕

正常路径：当前片段固定后，新片段从字幕区底部追加，固定视窗自动跟随最新内容，既有固定字幕保持不变（`FR-008`—`FR-010`、`AC-006`、`AC-007`）。

边界路径：内容超过固定视窗当前可见容量时，视窗仍自动跟随底部最新内容，不以扩大视窗替代跟随行为（`FR-010`、`AC-007`）。

## 业务状态、业务数据规则与不变量

- 当前片段依次处于“尚无可显示内容”“草稿/进行中”“已固定”状态；“已固定”状态不可逆。
- 英文当前片段可由稳定短语产生草稿，并在识别变化时保持为同一当前片段进行修订；最终确认使完整译文替换草稿。
- 中文当前片段保存识别原文，不保存中文翻译或改写结果；最终确认后原文固定。
- 同一时刻，底部只有当前未固定片段可因后续识别结果而变化；所有已固定片段保持不变。
- 新片段只能追加在既有字幕之后，不得插入并改写既有固定内容。
- 源语言业务取值仅为候选范围内的“英语”或“中文”；其他语言不属于本次产品契约。

## 错误与恢复行为

- 未获得语音采集许可时，流式字幕流程的前置条件不成立；本次未批准额外的拒绝提示或替代输入行为。
- 英文草稿与后续识别结果不一致时，通过修订当前草稿恢复一致；不得通过改写既有固定字幕恢复。
- 最终确认到达时，无论当前草稿经历多少次修订，均以完整译文替换草稿并转为固定状态。
- 新片段到达后，字幕视窗通过自动跟随底部恢复对最新内容的可见性。
- Azure Foundry 服务不可用、语言无法在候选范围内确定时的提示、重试、降级或恢复策略当前没有获批准的额外要求。

## 安全、隐私与可访问性行为

语音采集必须以发言人允许浏览器采集语音为前置条件。除该权限边界外，当前没有获批准的额外安全、隐私或可访问性产品行为要求。

## 性能、可靠性与其他质量边界

实时流式体验按 `NFR-001` 验收，其中“对标 Teams”及“不明显慢于指定参考实现”的具体比较边界仍待 `PQ-001` 决定。当前没有获批准的可用率、恢复时限、容量、正式质量等级或其他额外要求。

## 成功标准

- **SC-001**：在英语发言尚未最终确认时，参会者已经能看到由稳定短语形成的中文草稿，并能观察到草稿随输入更新。
- **SC-002**：英语片段最终确认后，草稿被完整译文替换并固定，后续输入不再改变该固定内容。
- **SC-003**：中文发言在过程中逐步显示识别原文，且未经过翻译或改写。
- **SC-004**：连续片段从字幕区底部追加，固定视窗自动跟随最新内容，既有固定字幕保持不变。
- **SC-005**：候选产品达到 `PQ-001` 最终批准的指定参考实现比较标准；在该问题获答前，此项不能作出最终通过结论。
- **SC-006**：中文片段最终确认后，其完整识别原文进入固定状态。

## 验收场景

### IQA-001 英文发言边说边出并修订草稿

- **追踪：** `INT-001`、`INT-003`、`INT-005`、`INT-009` / `US-001`、`US-002` / `FR-001`、`FR-004`、`FR-005` / `NFR-001` / `AC-001`、`AC-002`
- **前置条件：** 真实部署环境可使用真实 Azure Foundry 能力，已允许语音采集；准备可促使中间识别结果演进的合成英文语音。
- **操作：** 播放英文语音并在发言持续期间观察字幕，保留从首个草稿到后续修订的连续证据。
- **预期结果：** 发言未结束且片段未最终确认时，中文草稿已经出现；输入继续后，当前草稿可随识别结果更新。若仅在结束或停顿后一次性出现，则失败。
- **必需证据：** 带时间顺序的语音输入、当前片段草稿首次出现及至少一次可观察更新的端到端记录。

### IQA-002 英文最终译文替换并固定

- **追踪：** `INT-002`、`INT-006` / `US-002` / `FR-006`、`FR-008` / `AC-003`、`AC-004`
- **前置条件：** 真实部署环境可使用真实 Azure Foundry 能力，已允许语音采集；准备包含连续两个片段的合成英文语音。
- **操作：** 使首个片段经历草稿并最终确认，再输入第二个片段。
- **预期结果：** 首个片段的完整译文替换草稿并固定；第二个片段的识别与草稿变化不改写首个固定译文。
- **必需证据：** 首个片段最终确认前后及第二个片段更新期间的连续字幕记录。

### IQA-003 中文原文流式直显

- **追踪：** `INT-003`、`INT-004` / `US-003` / `FR-002`、`FR-003`、`FR-007` / `AC-005`
- **前置条件：** 真实部署环境可使用真实 Azure Foundry 语音转文本能力，已允许语音采集；准备内容明确的合成中文语音。
- **操作：** 播放中文语音并观察发言过程及最终确认后的字幕。
- **预期结果：** 发言过程中逐步显示并更新中文识别原文，结果未被翻译或改写。
- **必需证据：** 合成语音文本及对应的流式字幕连续记录。

### IQA-004 固定视窗追加与自动跟随

- **追踪：** `INT-006`、`INT-007` / `US-004` / `FR-008`、`FR-009`、`FR-010` / `AC-006`、`AC-007`
- **前置条件：** 已允许语音采集；准备足以让字幕内容超过固定视窗当前可见容量的多片段合成语音。
- **操作：** 连续输入多个可最终确认的片段，观察每次固定、追加及视窗位置。
- **预期结果：** 新片段依次从底部追加，视窗保持固定并自动跟随最新内容；先前固定字幕不被改写。
- **必需证据：** 覆盖内容达到视窗容量前后的连续端到端记录。

### IQA-005 与指定参考实现比较实时体验

- **追踪：** `INT-001`、`INT-009`、`INT-010` / `US-001` / `NFR-001` / `AC-008`
- **前置条件：** 候选产品和指定参考实现均可在真实部署环境使用真实集成服务运行；准备相同的合成英文语音；`PQ-001` 已获得人工答案。
- **操作：** 向两者提供相同语音，比较稳定短语草稿首次出现、持续更新和最终固定的可观察过程。
- **预期结果：** 候选产品满足 `PQ-001` 已批准的比较边界，且全过程保持边说边出；任一条件不满足即失败。
- **必需证据：** 可对应相同输入进度的候选产品与指定参考实现连续端到端记录，以及按获批比较边界作出的逐项判定。

### IQA-006 中文原文最终固定

- **追踪：** `INT-003`、`INT-004`、`INT-006` / `US-003` / `FR-011` / `AC-009`
- **前置条件：** 真实部署环境可使用真实 Azure Foundry 语音转文本能力，已允许语音采集；准备内容明确的合成中文语音。
- **操作：** 播放中文语音直至片段最终确认，再输入后续片段。
- **预期结果：** 首个中文片段的完整识别原文最终固定，后续片段不再改写该内容。
- **必需证据：** 首个中文片段最终确认前后及后续片段产生期间的连续字幕记录。

## 验收标准

- **AC-001**：英语或中文发言尚在进行且片段未最终确认时，字幕已经出现并可继续更新；仅在整句结束或停顿后一次性显示不通过。
- **AC-002**：英语稳定短语在当前片段最终确认前形成中文草稿，后续识别变化可修订当前草稿。
- **AC-003**：英文片段最终确认时，完整中文译文替换该片段草稿并进入固定状态。
- **AC-004**：任何后续片段或识别变化均不改写已经固定的字幕。
- **AC-005**：中文发言在过程中显示并更新识别原文，最终确认后固定完整原文，且不存在翻译或改写结果。
- **AC-006**：新片段在既有字幕之后从底部追加，不覆盖固定字幕。
- **AC-007**：字幕内容超过固定视窗当前可见容量时，视窗保持固定并自动跟随底部最新内容。
- **AC-008**：候选产品满足 `PQ-001` 人工批准的指定参考实现比较边界；在 `PQ-001` 未解决前，本条不可判定。
- **AC-009**：中文片段最终确认后，完整识别原文进入固定状态，后续输入不再改写该内容。

## 开放产品问题

- [ ] **PQ-001**（影响 `INT-001`、`INT-009`、`INT-010`）：在相同语音输入下，如何判定候选产品“不明显慢于”指定参考实现并达到同等实时体验？
  - **A（推荐）**：候选字幕不得持续落后指定参考实现一个或更多已稳定短语；允许由运行波动导致、随后追平的瞬时先后差异。该选项最贴近“不明显慢于”，且不增加绝对时限。
  - **B**：每个稳定短语的候选字幕首次显示均不得晚于指定参考实现。该选项提供更严格的逐短语边界。
  - **C**：由产品负责人给出允许候选字幕晚于指定参考实现的明确时间容差。该选项提供数值边界，但需要新增获批阈值。
  - **自定义答案**：产品负责人可在 `INT-001`、`INT-009`、`INT-010` 已批准的实时体验范围内填写其他明确、可判定的比较边界。

## 测试策略

### 开发者验证

- 以可重复的合成英语和中文语音覆盖流式中间结果、草稿修订、最终确认、连续片段以及超过固定视窗当前可见容量的场景。
- 在真实 Azure Foundry 集成下验证完整用户流程；局部处理结果、页面加载或健康检查只能作为辅助证据，不能替代端到端功能结果。
- 分别判定英语翻译路径、中文原文路径、固定内容不变式、底部追加与自动跟随；对每项保留输入、过程状态与最终结果之间可关联的证据。
- `PQ-001` 获答后，对相同合成英文语音执行候选产品与指定参考实现的比较验证。

### Independent QA 验收

- 在真实部署环境和真实 Azure Foundry 服务上，以黑盒方式独立执行 `IQA-001`—`IQA-006`；优先使用可提交、可重复的合成语音，不要求真人语音。
- Independent QA 必须观察完整用户流程中的过程更新与最终结果，不以 Mock、构建成功、health check、页面加载或单一静态截图替代。
- 每个场景均按其预期结果独立判定，并保留可证明语音输入进度、字幕变化、最终固定和视窗行为的连续证据。
- `IQA-005` 在 `PQ-001` 未获得人工答案前保持不可判定，不得自行选择推荐项作为验收结论。

### 总体通过与失败标准

总体通过要求 `IQA-001`—`IQA-006` 全部满足各自预期结果，且 `AC-001`—`AC-009` 均有真实端到端证据支持。任一必需场景失败、缺少必需证据、字幕退化为片段结束后一次性出现、固定字幕被改写，或候选产品不满足获批参考比较边界，均为总体失败。`PQ-001` 未解决时，可以完成其余场景，但不得给出本 Feature 的总体通过结论。

## 假设、依赖与范围外边界

- **假设**：一个“发言片段”以语音转写结果的最终确认为结束；该表述仅统一业务状态用语，不新增分段规则。
- **假设**：“固定视窗”表示新内容增加时字幕显示区域本身不随内容扩展；Intent 未批准具体尺寸。
- **依赖**：发言人允许浏览器采集语音；真实 Azure Foundry 语音转文本服务可用，英文路径还依赖其大模型能力；指定参考实现可用于 `IQA-005` 比较。
- **范围外**：英语和中文之外的源语言；中文发言的翻译或改写；固定字幕的后续改写；未获批准的服务错误提示、自动重试、降级策略；未获批准的额外安全、隐私、可访问性、可靠性、容量或正式质量等级。
