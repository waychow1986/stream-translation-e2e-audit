# 实时流式翻译产品规格

## 产品目标与边界

本规格将已批准的 `INT-001` 至 `INT-006` 转化为可观察、可验收的产品行为：会议期间，浏览器采集发言人语音，持续形成转写结果，自动检测客户指定语音转文本服务可自动检测的源语言，将识别结果持续翻译为中文并实时显示为字幕，使需要中文信息的参会者在发言进行时理解内容。

范围限于会议中的语音采集、流式转写、源语言自动检测、中文翻译和字幕展示。Teams 仅为连续字幕体验参照，不属于集成对象。会后全文、录音、字幕归档或导出，中文以外的目标语言，会议或参会者管理，以及人工翻译、校订或审核均不在范围内。`INT-006` 中客户指定服务的约束由后续技术阶段落实，本规格不据此选择实现方式。

## 参与者与权限

- **发言人**：提供会议语音；无需承担字幕操作职责，也未获批准任何管理权限。
- **需要中文字幕的参会者**：可在会议期间发起和停止实时字幕流程，并查看中文翻译字幕。
- **浏览器设备权限**：语音采集以浏览器已获得所需设备访问许可为前置条件；这不是产品角色或账户权限。
- 当前没有获批准的账户、角色分级、会议管理或参会者管理要求。

## 用户故事

### US-001 会议中查看连续中文字幕（P1）

作为需要中文字幕的参会者，我希望在发言人讲话期间持续看到由其语音转写并翻译得到的中文字幕，以便在会议进行时理解发言，而不是会后才获得结果。（`INT-001`、`INT-002`、`INT-003`、`INT-005`）

### US-002 自动适配获批范围内的源语言（P1）

作为需要中文字幕的参会者，我希望产品自动检测发言人的源语言，并覆盖客户指定语音转文本服务可自动检测的全部源语言，以便无需预先选择源语言即可查看中文翻译。（`INT-004`、`INT-005`）

## 功能需求

- **FR-001**：产品必须在参会者发起实时字幕流程后，通过浏览器采集发言人语音并持续形成流式转写结果。（`INT-003`）
- **FR-002**：产品必须自动检测输入语音的源语言；可接受范围为验收时客户指定语音转文本服务实际可自动检测的全部源语言。（`INT-004`）
- **FR-003**：产品必须将范围内源语言的识别结果翻译为中文，并在会议期间以字幕形式持续展示。（`INT-001`、`INT-005`）
- **FR-004**：参会者停止实时字幕流程后，产品必须停止采集，并且不得再基于停止后的语音产生新字幕。（`INT-003` 的最小行为闭合）
- **FR-005**：当语音无法被采集，或转写、语言检测、翻译中的任一步骤无法继续时，产品必须向参会者呈现当前无法继续产生字幕的可观察状态，不得将中断静默表现为仍在正常处理。（`INT-001`、`INT-003` 至 `INT-005` 的最小行为闭合）
- **FR-006**：造成中断的条件消除后，参会者必须能够重新发起实时字幕流程；后续有效语音按 `FR-001` 至 `FR-003` 处理，不要求补发中断期间的内容。（`INT-001`、`INT-003` 至 `INT-005` 的最小行为闭合）

## 产品质量要求

- **NFR-001**：对流程运行期间连续出现的有效语音，字幕必须在会议仍在进行时持续产生，而非仅生成单次结果或延迟到会后批量提供。（`INT-001`、`INT-002`）

除上述实时、连续体验外，当前没有获批准的额外产品质量要求或数值阈值。

## 领域术语

- **实时字幕流程**：从参会者发起语音采集，到参会者停止或流程发生中断期间，将语音持续转写、翻译并展示为字幕的业务过程。
- **源语言**：发言人当前输入语音所使用、并由产品自动检测的语言。
- **覆盖语言范围**：验收时客户指定语音转文本服务实际支持自动检测的全部源语言；该集合随指定服务的实际能力确定。
- **识别结果**：由输入语音形成、可供翻译的转写内容。
- **中文字幕**：识别结果翻译成中文后，在会议期间向参会者展示的文本。
- **有效语音**：具备采集条件，且能够被指定服务转写并自动检测为覆盖语言范围内源语言的语音。
- **中断**：采集、转写、语言检测或翻译无法继续，因而不能继续产生字幕的状态。

## 前置条件与触发条件

- 会议正在进行，发言人能够提供语音。
- 需要中文字幕的参会者已进入可使用实时字幕的浏览器场景。
- 浏览器具备可用的语音输入，并已获得采集所需的设备许可。
- 客户指定的语音转文本和翻译能力可用于本次流程；其实际自动检测语言集合可被验收方确认。
- 参会者发起实时字幕流程后触发采集、转写、语言检测、翻译和字幕展示；参会者停止流程时触发终止行为。

## 行为模型

### US-001 会议中查看连续中文字幕

- **正常路径**：参会者发起流程；产品采集语音并持续转写；自动检测源语言；将识别结果翻译为中文；在会议进行时持续展示字幕。（`FR-001`、`FR-003`、`NFR-001`、`AC-001`、`AC-003`）
- **替代路径**：发言人在同一流程中的后续有效语音继续经过相同处理并形成后续字幕，无需参会者逐段重新发起。（`NFR-001`、`AC-003`）
- **边界路径**：参会者在尚未出现可翻译语音时停止流程，产品停止采集且不产生停止后的新字幕。（`FR-004`、`AC-004`）
- **错误路径**：采集或任一后续处理步骤无法继续时，参会者看到流程中断状态，不会把无字幕误认为流程仍在正常处理。（`FR-005`、`AC-005`）
- **恢复路径**：中断条件消除后，参会者重新发起流程，后续有效语音恢复正常处理；中断期间内容无需补发。（`FR-006`、`AC-006`）

### US-002 自动适配获批范围内的源语言

- **正常路径**：输入覆盖范围内任一源语言的有效语音，产品无需参会者预选语言即可自动检测并输出中文字幕。（`FR-002`、`FR-003`、`AC-002`）
- **边界路径**：覆盖集合以验收时指定服务实际支持自动检测的语言集合为准，不以预先假定的固定语言清单替代。（`FR-002`、`AC-002`）
- **错误与恢复路径**：语言无法被检测或后续翻译无法继续时进入中断；条件消除并重新发起后处理后续有效语音。（`FR-005`、`FR-006`、`AC-005`、`AC-006`）

## 业务状态、业务数据规则与不变量

### 业务状态

1. **未启动**：尚未发起实时字幕流程，不采集语音。
2. **处理中**：流程已发起，产品持续接收并处理语音，可产生中文字幕。
3. **中断**：流程因采集、转写、语言检测或翻译无法继续而不能产生字幕，并呈现可观察状态。
4. **已停止**：参会者已停止流程，不再采集语音或产生基于停止后语音的新字幕。

允许的转换为：未启动到处理中；处理中到中断或已停止；中断在条件消除并重新发起后到处理中，或由参会者停止后到已停止；已停止经参会者再次发起后到处理中。

### 业务数据规则与不变量

- 每条中文字幕必须源自流程运行期间采集到的发言语音及其识别结果，不得凭空生成会议发言内容。
- 字幕目标语言固定为中文。
- 源语言由产品自动检测，不要求参会者预先选择。
- 可接受的源语言必须属于验收时指定服务实际可自动检测的语言集合。
- 字幕仅承担会议期间实时展示；本范围不承诺会后保留、归档、导出或补发。
- 停止状态下不得采集新的会议语音，也不得基于停止后的语音产生字幕。

## 错误与恢复行为

- 浏览器未取得语音输入许可、语音输入不可用或采集失败时，流程不得假装正常处理，必须呈现无法继续产生字幕的状态。
- 转写、源语言检测或翻译无法继续时，必须呈现中断状态；不得以未经处理的内容冒充中文字幕。
- 条件恢复后，由参会者重新发起流程处理后续有效语音；不承诺恢复或补发中断期间的语音和字幕。
- 对不属于覆盖语言范围或无法检测语言的语音，不要求生成中文字幕，按无法继续处理的中断行为处理。

## 安全、隐私与可访问性行为

宪章“三、数据安全”规定保护会议内容和凭据，并采取与实际需求及风险相称的安全与隐私措施，但未直接规定可从已批准 Intent 派生的具体用户可见产品行为；相关实现措施由后续技术阶段在不改变本规格行为的前提下确定。当前 Intent 没有获批准的额外安全、隐私或可访问性产品要求，因此本规格不新增 NFR、等级、权限行为或验收门禁。

## 性能、可靠性与其他质量边界

已批准范围仅要求 `NFR-001` 所述会议期间持续产生字幕的可观察结果，未批准具体响应时限、刷新频率、准确率、可用率、恢复时限、并发容量或正式质量等级。本规格不为这些维度添加数值阈值或额外验收义务。

## 成功标准

- **SC-001**：在会议进行期间，范围内源语言的有效发言能够形成持续展示的中文字幕，使参会者无需等待会后结果即可阅读。（`INT-001`、`INT-002`、`INT-005`）
- **SC-002**：验收时指定服务实际可自动检测的每一种源语言均属于产品接受范围，且无需参会者预选源语言即可进入中文翻译流程。（`INT-004`）
- **SC-003**：连续有效发言产生连续字幕结果，而非只产生单次结果或会后批量结果。（`INT-002`）
- **SC-004**：流程无法继续时，参会者能够区分中断与正常处理，并能在条件消除后重新发起后续语音处理。（`INT-001`、`INT-003` 至 `INT-005` 的最小行为闭合）

## 验收场景

### IQA-001 范围内源语言形成实时中文字幕

- **追踪：** `INT-001`、`INT-003`、`INT-005` / `US-001` / `FR-001`、`FR-003` / `NFR-001` / `AC-001`
- **前置条件：** 会议正在进行，语音输入及所需许可可用，选取一种属于覆盖语言范围的源语言。
- **操作：** 参会者发起实时字幕流程，发言人使用该语言提供可转写的会议语音。
- **预期结果：** 产品采集语音、形成识别结果、自动检测语言并在会议进行时持续展示对应的中文字幕。
- **必需证据：** 可核验的输入语言与发言内容、流程运行状态、会议期间实际显示的中文字幕及其与发言含义的一致关系。

### IQA-002 验证全部自动检测语言的范围边界

- **追踪：** `INT-004`、`INT-005` / `US-002` / `FR-002`、`FR-003` / `AC-002`
- **前置条件：** 已取得验收时客户指定语音转文本服务实际可自动检测的完整源语言集合，并为集合中各语言准备可转写语音。
- **操作：** 对集合中的每一种源语言分别发起实时字幕流程并提供对应语音，不预选源语言。
- **预期结果：** 每一种语言均被自动检测并进入中文翻译字幕流程；产品未以更小的固定语言清单限制接受范围。
- **必需证据：** 验收时权威语言集合、各语言输入标识、自动检测结果和对应中文字幕结果。

### IQA-003 连续发言形成连续字幕

- **追踪：** `INT-001`、`INT-002` / `US-001` / `FR-001`、`FR-003` / `NFR-001` / `AC-003`
- **前置条件：** 实时字幕流程可正常运行。
- **操作：** 发言人在同一运行流程中连续提供多个可区分的有效发言内容。
- **预期结果：** 会议进行期间持续出现与各段发言对应的中文字幕，不要求逐段重新发起，也不是在停止后一次性批量出现。
- **必需证据：** 可区分的连续输入内容、流程未被逐段重启的状态记录，以及会议期间连续出现的对应字幕。

### IQA-004 停止后的采集边界

- **追踪：** `INT-003` / `US-001` / `FR-004` / `AC-004`
- **前置条件：** 实时字幕流程正在处理语音。
- **操作：** 参会者停止流程，随后继续提供可转写语音。
- **预期结果：** 产品进入已停止状态，不采集停止后的语音，也不基于该语音产生新字幕。
- **必需证据：** 停止操作、已停止状态，以及停止后无新增语音采集和对应新字幕的可核验结果。

### IQA-005 中断状态可见

- **追踪：** `INT-001`、`INT-003`、`INT-004`、`INT-005` / `US-001`、`US-002` / `FR-005` / `AC-005`
- **前置条件：** 实时字幕流程已发起。
- **操作：** 分别使语音采集不可用，以及使转写、语言检测或翻译无法继续。
- **预期结果：** 每种情况下均呈现当前无法继续产生字幕的可观察状态，不将中断静默表现为正常处理，也不以未经处理的内容冒充中文字幕。
- **必需证据：** 每类中断条件、对应可观察状态，以及中断期间未产生伪装成正常结果的字幕。

### IQA-006 中断后恢复后续处理

- **追踪：** `INT-001`、`INT-003`、`INT-004`、`INT-005` / `US-001`、`US-002` / `FR-006` / `AC-006`
- **前置条件：** 流程处于中断状态。
- **操作：** 消除中断条件，参会者重新发起流程并提供范围内源语言的有效语音。
- **预期结果：** 后续有效语音恢复转写、自动语言检测、中文翻译和字幕展示；不要求补发中断期间内容。
- **必需证据：** 中断条件消除、重新发起、后续输入及其中文字幕结果。

## 验收标准

- **AC-001**：给定会议正在进行且采集条件可用，当参会者发起流程并输入范围内源语言的有效语音时，会议期间显示由该语音识别结果翻译得到的中文字幕。
- **AC-002**：给定验收时指定服务实际可自动检测的完整语言集合，当逐一输入集合中各语言的有效语音且不预选源语言时，每种语言均被自动检测并进入中文翻译字幕流程。
- **AC-003**：给定流程持续运行，当发言人连续提供多个可区分的有效发言内容时，会议期间持续出现对应中文字幕，而不是仅出现单次结果或停止后批量结果。
- **AC-004**：给定流程正在运行，当参会者停止流程并继续提供语音时，产品不采集停止后的语音，也不产生基于该语音的新字幕。
- **AC-005**：给定流程已发起，当采集、转写、语言检测或翻译无法继续时，参会者看到无法继续产生字幕的状态，且中断不被静默表现为正常处理。
- **AC-006**：给定流程已中断，当条件消除、参会者重新发起并提供后续有效语音时，后续语音重新形成中文字幕；中断期间内容无需补发。

## 测试策略

### 开发者验证

- 以需求和验收标准为边界验证从浏览器语音采集、流式转写、自动语言检测、中文翻译到会议中字幕展示的完整用户流程；局部检查只能作为辅助证据。
- 覆盖正常流、连续多段发言、全部获批源语言范围、停止边界、各处理阶段中断以及条件消除后的重新发起。
- 对每次验证保留可对应输入、状态和用户可见输出的结果，不以构造的成功状态替代完整流程结果。
- 验证不扩展到范围外能力，也不把未批准的数值质量目标变成通过条件。

### Independent QA 验收

- 独立执行 `IQA-001` 至 `IQA-006`，按每个场景列明的前置条件、操作、预期结果和必需证据判定。
- `IQA-001` 和 `IQA-003` 必须验证正在进行的会议中的完整、连续用户流程，而非页面加载、单个处理步骤或会后结果。
- `IQA-002` 使用验收时可核验的权威语言集合确定覆盖边界，不以抽样通过替代“全部自动检测语言”的已批准范围。
- 中断与恢复场景分别判定，不得以正常路径通过代替错误路径和恢复路径证据。

### 总体通过与失败标准

- **通过**：`IQA-001` 至 `IQA-006` 全部满足各自预期结果和必需证据，且没有观察到与 `FR-001` 至 `FR-006`、`NFR-001` 或业务不变量相冲突的用户可见行为。
- **失败**：任一必需场景未执行、缺少必需证据、任一验收标准不满足，或结果仅证明局部步骤而未证明相应完整用户流程。
- 未获批准的数值指标、额外质量等级和范围外能力不参与本次通过或失败判定。

## 假设、依赖与范围外边界

### 假设

- “中文”沿用 Intent 的原始表述，不在本阶段默认细分书写体系或地区变体；该表达默认不产生新的 Requirement 或验收门禁。
- 单次验收中的覆盖语言集合以验收开始时可核验的指定服务实际自动检测能力为准；这是对动态范围表述的解释，不固定或扩大语言集合。
- 未批准同时多人重叠发言、单段发言内混用多种语言或会议中途自动保留历史字幕的额外行为，这些情况不作为本次验收义务。

### 依赖

- 客户指定语音转文本服务和大模型实际能够支持所要求的转写、自动语言检测和中文翻译用途。
- 可接受源语言范围依赖验收时客户指定语音转文本服务的实际自动检测能力。
- 浏览器设备具备可用语音输入且获得采集许可。

### 范围外边界

- 会后全文、录音、字幕归档、导出或中断内容补发。
- 中文以外的目标字幕语言。
- 会议管理、参会者管理或 Teams 集成。
- 人工翻译、人工校订或人工审核。
- 未经批准的性能数值、可靠性等级、安全或隐私产品行为、可访问性等级及合规目标。
